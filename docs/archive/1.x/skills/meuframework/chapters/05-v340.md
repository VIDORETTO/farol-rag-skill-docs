# Capítulo 5 — Release notes v3.4.0

> Fontes: `documents/examples/v3.4.0-release-notes.md` (indexado no RAG).

## Mudanças de contrato

1. **Novo kwarg `compress`** em `client.request()` (padrão `False`) — gzip via
   `Accept-Encoding: gzip`; posicional sem alteração (compatível com v3.2/3.3).
2. **`GET /v3/health` agora exige `x-acme-key`** — breaking para health checks
   antigos (resp. 401 sem header).
3. **`Client.log_requests = True`** — 1 linha JSON anônima por request em stderr.

## Deprecations em execução

- `client.join(endpoint, key)` → removido na v4 (aviso desde a v3.2.0).
- `body: str` removido (só `dict` desde a v3.2.0).

## Não mudou

- `page_size` máx. 500; Python 3.11+/Node 18+; `retries` padrão 2.

Aplicar a regra do changelog do capítulo 4: adições → mudanças → deprecações.
