# Estado de `master-evolution`

Este diretório registra o plano e a evidência da evolução Farol 1.x. Seus
tickets estão concluídos historicamente e não formam o backlog atual.

A evolução normativa é [Farol 2.0](../../specs/farol-2/README.md). O TK-017 já
executou a remoção contratual de Mercado Livre, curso, página e oferta: esses
conceitos não existem mais no runtime, schemas, CLI, exports, presets ou
fixtures 2.0. Este diretório mantém apenas o registro histórico 1.x; as
referências a esses artefatos não são requisitos do produto novo.
