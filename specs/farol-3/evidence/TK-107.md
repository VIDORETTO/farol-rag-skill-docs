# TK-107 evidence — vídeo, áudio e legendas

Status: `implemented`; YouTube real `not_run` a partir desta VPS (bloqueio de bot).

## Entregue

- `docops/transcripts.py`: parser WebVTT/SRT (remove markup, funde legendas
  automáticas repetidas), Markdown com parágrafos `[HH:MM:SS]` (~45 s) e
  capítulos como `## título`, metadados de proveniência (legenda manual,
  automática, arquivo ou ASR local).
- Normalizador: `.vtt`/`.srt` aceitos nativamente (contrato 2.0 alterado por este
  ticket; ASS/SSA seguem externos); áudio/vídeo (`mp3 m4a wav ogg flac mp4 webm
  mkv mov`) via `faster-whisper` local; sem o extra → `asr_unavailable`; mídia
  corrompida → `media_unreadable` (antes derrubava o processo).
- Índice/MCP: locator `timestamp` por bloco; citação `…:LINHA (at HH:MM:SS)`.
- Jornada: `farol add <url do YouTube>` → legendas (manuais primeiro), capítulos,
  título e licença declarada (Creative Commons → `CC-BY-3.0`; padrão → aviso de
  uso pessoal); sem yt-dlp → `extra_required`; bloqueio de bot → `youtube_blocked`
  com orientação (cookies via `FAROL_YTDLP_COOKIES`, rede residencial ou adicionar
  o `.vtt`/áudio baixado).
- Extra `media = ["yt-dlp==2026.8.19", "faster-whisper==1.2.1"]`.
