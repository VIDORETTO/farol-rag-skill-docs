# TK-116 evidence — biblioteca e MCP multi-pacote

Status: `implemented`.

## Entregue

- MCP multi-pacote dentro de um projeto (`farol mcp --project .`, commit `603a636`).
- `docops/library.py`: `farol library add|list|remove` (registro em
  `~/.farol/library.json`, `FAROL_HOME`), idempotente; `farol mcp --library`
  serve todos os pacotes de todos os projetos como `projeto/fonte`.
- Isolamento: um pacote com índice danificado não derruba a busca; o resultado
  lista `unavailable: [{package, code: index_unreadable}]`.
