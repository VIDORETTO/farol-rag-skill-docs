# TK-113 evidence — conteúdo hostil e prompt injection

Status: `implemented`.

## Entregue

- `docops/safety.py`: classificação determinística `none|suspicious|high` com
  motivos; `dominated_by_high_risk()` para quarentena só de documentos dominados
  por diretivas (≥ 25% dos parágrafos).
- Normalizador: citar um ataque não põe mais o documento inteiro em quarentena.
- Índice local: cada bloco recebe `risk`; blocos `high` são excluídos da busca
  por padrão (`include_high_risk` só para inspeção local); formato do índice → v2.
- MCP: cada hit traz `risk`; nota de conteúdo não confiável mantida.
- Síntese (TK-105): blocos `high` nunca entram nas tarefas; skills com texto
  `high` são rejeitadas (`unsafe_content`).
- `SECURITY.md`: seção “Conteúdo hostil e prompt injection” com limites.

## Verificação

- Corpus adversarial rotulado à mão (`tests/fixtures/adversarial/cases.json`,
  20 casos EN/PT, incluindo zero-width, Unicode tags e bidi): 20/20.
- Falsos positivos no corpus real: httpx 0/961 parágrafos; paper 1 `suspicious`
  (prompt citado, correto); Pro Git 1 falso `high` (“You are now well prepared…”)
  → caso adicionado ao corpus (RED) e padrão corrigido; 0 falsos `high` depois.
- RED observado para documento que cita ataque e para blocos `high` no MCP.
- Paper GraphRAG passou de `blocked` para `measured` (recall@5 1,0).
