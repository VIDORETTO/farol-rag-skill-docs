# TK-108 evidence — papers e PDFs estruturados

Status: `implemented`.

## Entregue

- PDF → Markdown com **sumário embutido** (bookmarks) como `### seção` dentro de
  cada `## Page N` (seção carregada entre páginas e quebrada onde o título aparece),
  metadados (`Title`, `Pages`, `arXiv`, `DOI`) ao final do documento.
- Índice: todo bloco de PDF ganha locator `page` (intervalo até o próximo
  `## Page`); citação `rag/documents/x.md:LINHA (page N)`.
- Síntese: seções agrupadas pelo sumário, ignorando `Page N`.
- `farol add arXiv:<id>`: baixa o PDF uma vez para `.farol/downloads/`, detecta a
  licença declarada no arXiv (CC → SPDX; `nonexclusive-distrib` → aviso de uso
  privado) e o título. Verificado contra o arXiv real (2404.16130v2 → CC-BY-4.0,
  título correto, 27 seções reais).

## Bugs estruturais encontrados pela régua real e corrigidos

1. `TextWebExtractor`: `heading_path[:level-1]` tornava o primeiro H2 raiz eterna
   em documentos sem H1 (`["Page 1", "Page 8", …]`) → pilha de níveis (RED observado).
2. Texto de PDF lido como Markdown: `# On branch master` virava H1 e bagunçava a
   hierarquia do livro → linhas com sintaxe Markdown acidental são escapadas.
3. Scaffold 2.0 usava comentários de blocos de código como títulos (commit anterior).
