# TK-109 — `farol connect` e instalação em um comando

## Objetivo e limites

`farol connect <harness> [--scope user|project] [--dry-run] [--remove]` copia
ou referencia skills/router e registra o MCP `farol` no arquivo de config do
harness, preservando o conteúdo existente:

| Harness | Skills | MCP |
|---|---|---|
| claude-code | `.claude/skills/` | `.mcp.json` / `claude mcp add` |
| codex | `~/.codex/skills/` / `AGENTS.md` | `~/.codex/config.toml` |
| cursor | `.cursor/rules/` | `.cursor/mcp.json` |
| opencode | `.opencode/` | `opencode.json` |
| generic | imprime instruções | imprime bloco JSON |

Instalação: `pipx install <pacote>` / `uv tool install <pacote>`; bootstrap atual
continua para desenvolvimento.
