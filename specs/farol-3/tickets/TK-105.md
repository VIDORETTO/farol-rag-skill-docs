# TK-105 — Tarefas de síntese executadas pela IA do usuário

## Objetivo e limites

Levar a destilação estilo book-to-skill para o caminho do produto. O Farol emite
uma tarefa por tópico aprovado com: projeção IR (blocos com ids e locators),
template de skill (SKILL.md ≤ ~4k tokens + capítulos com Core Idea, Frameworks,
Anti-patterns, Takeaways; glossary, patterns, cheatsheet), idioma, budget,
regras de lineage e schema de saída. A IA do usuário escreve os arquivos; o
`SynthesisEngine` valida e aceita/rejeita com motivos.

Livros grandes: a tarefa é fatiada por capítulo (map) + tarefa de consolidação
(reduce) para caber no contexto de qualquer modelo.

Não inclui: chamar modelo pelo core; taxonomia (TK-106).

## Decisões já resolvidas

- Template e regras de qualidade derivados do book-to-skill (MIT) com atribuição.
- Scaffold estrutural continua existindo, mas marcado `generated_by: scaffold`
  e nunca contado como skill destilada.
- `scripts/run_book_to_skill_profile.py` passa a usar o protocolo público
  (remove fixture/taxonomia hardcoded).

## Condição de retorno

Se modelos comuns não conseguirem produzir lineage por bloco, propor lineage por
seção (granularidade maior) mantendo verificabilidade.
