# TK-119 — Prova de valor: com vs. sem Farol

## Objetivo e limites

Runner que, para um harness/modelo informado pelo operador, faz as mesmas
perguntas do golden em três braços: (a) sem contexto, (b) corpus bruto no
contexto até o limite, (c) Farol (skills + MCP). Mede acerto (contra resposta
de referência revisada), citações verificáveis, alucinação e tokens de contexto.

O core continua sem chamar modelo: o runner é script opt-in que invoca um
harness CLI configurado pelo usuário (ex.: `claude -p`, `codex exec`), com
custo exibido antes de rodar. Ausência de harness = `not_run`.

## Sequência TDD

- [ ] 119.1 RED: avaliador de respostas (determinístico: citação resolve para bloco que contém a evidência esperada) com casos escritos à mão.
- [ ] 119.2 RED: runner com harness fake (script de teste) produz relatório com os três braços e denominadores.
- [ ] 119.3 Execução real em ≥ 2 harnesses; `docs/BENCHMARK.md` com método, versões, custo e limites.
