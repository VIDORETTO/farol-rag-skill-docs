# TK-211 evidence — skill composta por várias fontes

Status: `implemented` (D-304 aceita: convive com as skills por fonte).

## Entregue

- `farol skill compose <nome> --from <id> <id>… [--language]`
  (`docops/composite.py`): `farol.json` ganha `skills[]` (chave aditiva) e
  `packages/@<nome>/manifest.json` (`kind: composite`, membros). Menos de duas
  fontes conhecidas → `composite_member_unknown`.
- O plano de síntese do composto lê os blocos dos membros (caminho prefixado
  pelo membro, bloco marcado com `package`); outline/capítulos/core idênticos
  aos de uma fonte. A lineage ganha `sources[]` com `package` + `block_id`
  (campo aditivo; `block_ids` mantido). A instalação não exige corpus, índice
  nem harness próprios.
- `farol build` planeja o composto quando todos os membros estão indexados;
  `farol status` lista `skills[]`; `farol sync` marca `stale` os capítulos do
  composto que citam blocos removidos de qualquer membro.
- `farol add … --no-skill` (`sources[].skill: false`): só índice; estado `indexed`.
- MCP (`farol mcp --project`): `list_skills`/`get_skill` incluem o composto
  (`package: "@nome"`); `search_knowledge(package="@nome")` pesquisa os membros.
  `farol connect` instala a skill composta e a lista no router do projeto.
