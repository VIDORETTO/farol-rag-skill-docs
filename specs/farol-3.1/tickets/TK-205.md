# TK-205 — Perfil de embedding com prefixos e troca medida

## Objetivo e limites

O padrão `paraphrase-multilingual-MiniLM-L12-v2` (`docops/backends/semantic.py:16`)
foi escolhido no 3.0 porque `multilingual-e5-small` não existia no fastembed.
O fastembed 0.8.1 oferece alternativas permissivas (ver [decisions.md](../decisions.md)).

1. Perfil de embedding passa a registrar `query_prefix`/`passage_prefix`
   (ex.: `query: `/`passage: ` para e5; instrução de consulta para Qwen3) e os
   aplica em `embed_query`/`embed_documents`; o perfil entra no fingerprint.
2. `farol build` detecta perfil diferente do índice ativo e **reconstrói** sem
   pedir nada (regra de `docs/COMPATIBILITY.md`); `farol doctor --fix` idem.
3. `scripts/benchmark_embeddings.py --json`: para cada candidato, recall@5,
   MRR@5 (teste e validação, PT separado), tempo de build do livro, RAM de pico
   e tamanho do modelo.
4. Trocar o padrão **só** se D-302 for cumprido; registrar evidência nova (invariante do `AGENTS.md`).
