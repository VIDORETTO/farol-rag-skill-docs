# Farol 3.1 — planejamento

Evolução **aditiva** (minor) do Farol 3.0.0 para cumprir a intenção original
por inteiro: transformar **qualquer** conteúdo (livro, curso, vídeo, paper,
docs, repositório) em skills destiladas + evidência consultável, com
recuperação mais precisa, destilação mais rápida e cursos como conceito de
primeira classe.

- [spec.md](spec.md) — intenção, diagnóstico (G1–G10), jornadas, critérios de aceite e sucesso.
- [plan.md](plan.md) — abordagem, alternativas, seams, roteamento SDD, ondas e riscos.
- [tdd.md](tdd.md) — estratégia de testes: fixtures, mapa teste→ticket, ordem RED/GREEN e comandos.
- [decisions.md](decisions.md) — decisões propostas (D-301–D-308) e o que cada uma bloqueia.
- [backlog.md](backlog.md) — fases, ordem topológica, grafo e rastreabilidade.
- [tickets/](tickets) — unidades canônicas de trabalho (`hybrid/ticket`, TK-201–TK-218).
- [state.json](state.json) — estado agregado enxuto (≤ 10 KB).

`specs/farol-3/` continua sendo a fonte normativa do 3.0 (inclusive o beta
TK-122). Este esforço parte do SHA `6ee4ffe` (`main`, release 3.0.0 registrada).
